Mutation testing, minus the pain

Break your tests before prod does.

BugBait plants realistic bugs in your code, runs your test suite against each one, and writes verified tests for every gap it finds. Your code is never touched — it all happens on throwaway copies.

Test your project Star on GitHub

How it works

  1. 1Saboteur plants bugs

    An AI agent studies your code and plants small, realistic mistakes — off-by-ones, flipped operators, dropped guards. Each gets a realism rating; artificial ones are thrown out.

  2. 2Sandbox scores your tests

    Every bug runs against your full suite in its own throwaway copy. Caught means a test failed; survived means a real gap. Score: caught ÷ planted.

  3. 3Fixer writes the missing tests

    A second agent writes a test per survivor — each verified to pass on your code and fail on the bug. Add them to your project or open a pull request.

Three ways to run it: the dashboard (point-and-click, pick repos after connecting GitHub), the command line, or the VS Code extension (underlines surviving bugs right in your editor).

Get started in two minutes

  1. Clone it and install the four dependencies:

    git clone https://github.com/AVI2907/bugbait.git
cd bugbait && pip install -r requirements.txt

  2. Add your model key to .env:

    META_API_KEY=your_key_here

  3. Run the demo — no key needed for this one:

    python3 main.py calculator --offline

  4. Then open the dashboard and test anything:

    python3 app.py   # opens http://localhost:5050

Your code stays on your machine. Nothing is pushed anywhere unless you click “Open pull request”.
